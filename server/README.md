This folder contains discrete microservice useful in generating or creating ads.


## generate-images

This is useful for prototyping advertisements or finding a style that works.


## edit-image

A wholesale modification agent that takes an existing photo and requested prompt, decides how to edit it and ensure a brand-safe product sits in it.

Accepts a 3-dimensional OBJ file and/or a 2-d product image and selects from available models to attempt to make the appropriate edits.
